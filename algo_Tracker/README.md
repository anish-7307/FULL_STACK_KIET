# 🚀 DSA Tracker

A beautiful, modern web application to track your Data Structures and Algorithms progress. Master coding interviews with style! 💪

![DSA Tracker Preview](https://via.placeholder.com/800x400/6366f1/ffffff?text=DSA+Tracker+Preview)

## ✨ Features

- 🎯 **Track Progress**: Mark problems as solved and monitor your advancement
- ⭐ **Bookmark Problems**: Save important questions for later review
- 🔍 **Smart Filtering**: Filter by difficulty, topic, status, and search terms
- 📊 **Beautiful Stats**: Visual progress tracking with animated charts
- 💾 **Persistent Storage**: Your progress is saved locally in your browser
- 📱 **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- 🌙 **Dark Theme**: Easy on the eyes with a modern dark interface
- ⚡ **Fast & Lightweight**: Built with React and Vite for optimal performance

## 🎮 How to Use

1. **Browse Problems**: View the curated list of DSA problems
2. **Mark as Solved**: Click the checkbox to mark problems you've completed
3. **Bookmark**: Click the star to save problems for later
4. **Filter & Search**: Use the filters to find specific problems
5. **Track Progress**: Watch your stats update in real-time

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Heroicons & Emoji
- **Storage**: LocalStorage API
- **Deployment**: Static hosting ready

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/dsa-tracker.git
   cd dsa-tracker
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   ```
   http://localhost:5173
   ```

### Build for Production

```bash
npm run build
npm run preview
```
